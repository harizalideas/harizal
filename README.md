# 🎂 Selamat Ulang Tahun Harizal! 🎉✨

Aplikasi web interaktif ucapan selamat ulang tahun modern berbasis **Next.js**, menampilkan karakter interaktif **Mochi** yang terinspirasi dari proyek open-source notch companion [Coucou](https://github.com/louis-cfm/coucou).

Telah dideploy dan tayang di: **[https://harizal.vercel.app](https://harizal.vercel.app)**

---

## ✨ Fitur-Fitur Interaktif

- **🐾 Karakter Mochi Interaktif (Coucou Style)**:
  - Bentuk *squircle* matematis dinamis (Lamé curve $n = 3.2$) dengan rendering beresolusi tinggi (Retina High-DPI).
  - **Eye Tracking**: Mata Mochi secara halus mengikuti ke mana kursor mouse atau sentuhan jari Anda bergerak.
  - **Natural Blinking**: Kedipan mata alami dan ekspresi wajah dinamis (bahagia, senyum, kagum, dan pusing jika dicolek berkali-kali).
  - **Physics Bouncy Squash & Stretch**: Animasi pegas membal saat Mochi disentuh / dicolek.
  - **Tangan Melambai (*Waving*)**: Tangan kanan melambai menyapa dengan lembut (*Coucou wave*).
  - **Pipi Merona (*Blushing*)**: Pipi merah muda yang bersinar saat Mochi diajak berinteraksi.

- **🕯️ Tiup Lilin Ulang Tahun**:
  - Kue ulang tahun dengan lilin menyala berkerlip.
  - Tombol interaktif untuk meniup lilin yang menghasilkan animasi kepulan asap partikel dan hujan konfeti warna-warni!

- **🎵 Web Audio Synthesizer (Zero-Dependency)**:
  - Musik melodi *"Happy Birthday To You"* marimba/chime yang dimainkan langsung melalui Web Audio API tanpa perlu file eksternal.
  - Efek suara *pop/boing* saat menyentuh Mochi dan efek desis angin saat meniup lilin.

- **👑 Kustomisasi Topi Pesta**:
  - Ganti aksesoris kepala Mochi (Topi Kerucut Pesta Bergaris, Mahkota Emas Raja, atau Pita Pesta).

- **🏝️ Dynamic Island / Mac Notch**:
  - Desain *Dynamic Island* ala macOS / iOS di bagian atas yang bisa diklik untuk membuka/menutup status perayaan.

- **💌 Papan Doa & Harapan (Wish Board)**:
  - Kolom ucapan dan doa interaktif yang tersimpan secara lokal dan menghamburkan konfeti saat dikirim.

- **🎁 Kado Kejutan (Surprise Gift Box)**:
  - Kotak kado 3D membal yang dapat dibuka untuk melihat kartu ucapan istimewa dan kode keberuntungan ulang tahun.

## 🚀 Menjalankan Secara Lokal

```bash
# Install dependensi
npm install

# Jalankan server pengembangan
npm run dev

# Buka http://localhost:3000 di browser
```
